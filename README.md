# Portal RSC UFPE

Portal de apoio ao Reconhecimento de Saberes e Competências (RSC) dos servidores técnico-administrativos da UFPE, desenvolvido pela Unidade de Desenvolvimento de Pessoal (UDP) da Divisão de Gestão de Pessoas (DIVGP) do Hospital das Clínicas da UFPE/HU Brasil.

## Estrutura
- assets/: estilos, scripts, imagens e arquivos de apoio.
- documentos/: manuais, ofícios, portarias e documentos institucionais.
- páginas HTML na raiz.

## Publicação
O portal é estático e pode ser publicado no GitHub Pages.

## Atualização
Substitua documentos mantendo os mesmos nomes quando possível e revise os links internos antes de publicar.

## Créditos
UDP/DIVGP – HC-UFPE/HU Brasil.
